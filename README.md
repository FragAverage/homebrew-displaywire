# Homebrew tap for DisplayWire

```
brew install --cask FragAverage/displaywire/displaywire
```

Installs the Mac app from [FragAverage/displaywire](https://github.com/FragAverage/displaywire). The app updates
itself (**DisplayWire > Check for Updates…**), and this tap follows each release automatically.

To remove it: `brew uninstall --cask displaywire` (add `--zap` to delete its saved PCs too).
